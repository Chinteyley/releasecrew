# ReleaseCrew

A crew of agents that turns a GitHub repo + release tag into a **verified** launch kit: changelog, X thread, and a short trailer.

Built during **neatHack Oct 10–12**.

```bash
npx tsx src/cli.ts --repo honojs/hono --tag v4.10.1 --demo-failures
```

Partner stack: [neatlogs](https://neatlogs.com) traces every step, [Entire](https://entire.io) maps this repo while we build, [cfo.ai](https://cfo.ai) models the business. Full architecture, evidence checklist, and run instructions land in the next commits.
