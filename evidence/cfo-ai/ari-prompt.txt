Build an 18-month financial model for ReleaseCrew, a multi-agent SaaS that turns a GitHub release into verified notes, an X thread, and a trailer. Month 0 = November 2026. Use the assumptions below (mark every number as an assumption). Create Main as the Base case, plus Growth, Price cut, and Hiring freeze scenarios.

WHAT THE PRODUCT IS
ReleaseCrew is a crew of agents that turns a GitHub repo + release tag into a verified launch kit: changelog, X thread, and a short trailer. The verifier rejects invented features. State is durable, so a failed run resumes. Customer: open-source maintainers, DX teams, and product marketers who ship weekly and still write release notes by hand.

PRICING (model these three plans)
- Indie: $29/month, solo maintainers, 20 kits/month, 1 seat
- Team: $149/month, product + DX, 150 kits/month, 5 seats
- Launch: $499/month, companies with a release train, 600 kits/month, 20 seats
- Annual: 2 months free (Indie $290, Team $1,490, Launch $4,990)
- Overage: $2.50 per extra kit. Trailer render over 30s: +$0.40

STARTING CUSTOMERS (month 0 = Nov 2026)
- Indie: 40, Team: 6, Launch: 1
- Paid conversion from the neatHack demo waitlist: 12 Indie in month 1

- Collection: 100% card, billed in advance, recognized monthly
